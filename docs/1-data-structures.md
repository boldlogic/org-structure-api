# Структура БД и JSON API

Все таблицы находятся в схеме `org`.

## org.departments - подразделения

| № | Колонка | Тип | Nullable | Default | Описание |
| --- | --- | --- | --- | --- | --- |
| 1 | id | SERIAL | Нет | sequence | Идентификатор подразделения. Первичный ключ. |
| 2 | name | VARCHAR(200) | Нет | - | Название подразделения. Обязательно. Уникальность проверяется в пределах одного родителя. |
| 3 | parent_id | INT | Да | - | Родительское подразделение. Ссылается на departments.id; при удалении родителя дочерние подразделения удаляются каскадно. |
| 4 | created_at | TIMESTAMPTZ | Нет | NOW() | Дата и время создания записи. |

## org.employees - сотрудники

| № | Колонка | Тип | Nullable | Default | Описание |
| --- | --- | --- | --- | --- | --- |
| 1 | id | SERIAL | Нет | sequence | Идентификатор сотрудника. Первичный ключ. |
| 2 | department_id | INT | Нет | - | Подразделение сотрудника. Ссылается на departments.id; при удалении подразделения сотрудник удаляется каскадно. |
| 3 | full_name | VARCHAR(200) | Нет | - | Полное имя сотрудника. Обязательно. |
| 4 | position | VARCHAR(200) | Нет | - | Должность сотрудника. Обязательно. |
| 5 | hired_at | DATE | Да | - | Дата найма. Не обязательна. |
| 6 | created_at | TIMESTAMPTZ | Нет | NOW() | Дата и время создания записи. |


## JSON в API

### Объект `department`

| Параметр   | Описание                       | Тип     | Обязательность | Ограничения/Формат |
| ---------- | ------------------------------ | ------- | -------------- | ------------------ |
| id         | Идентификатор подразделения    | integer | Да             | -                  |
| name       | Название подразделения         | string  | Да             | -                  |
| parent_id  | ID родительского подразделения | integer | Нет            | -                  |
| created_at | Дата и время создания          | string  | Да             | `date-time`        |

### Объект `employee`

| Параметр      | Описание                 | Тип     | Обязательность | Ограничения/Формат |
| ------------- | ------------------------ | ------- | -------------- | ------------------ |
| id            | Идентификатор сотрудника | integer | Да             | -                  |
| department_id | ID подразделения         | integer | Да             | -                  |
| full_name     | ФИО сотрудника           | string  | Да             | -                  |
| position      | Должность                | string  | Да             | -                  |
| hired_at      | Дата найма               | string  | Нет            | `date`             |
| created_at    | Дата и время создания    | string  | Да             | `date-time`        |
